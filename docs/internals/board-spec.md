## 阶段语义（必须一致）

- `backlog 待启动`：没有会话（外部项目：未接管一律待启动，git 活动不证明完成）。
- `active 进行中`：有会话在跑（外部项目：有未提交改动）。
- `review 等我把关`：卡在审批 / 提问 / 待确认计划。
- `ship 待交付`：有开着的 PR。
- `paused 暂停`：**只能手动设置**（或会话 snooze），推导永远不产生 paused。
- `done 已收敛`：T3 会话都收敛。外部项目不推导 done（完成状态必须另行核验）。默认折叠成窄列。
- **沉睡**：外部项目最近活动 > 30 天 → 所在列底部折叠为「N 个沉睡项目」按钮，点击展开。

## 已知边界

- 原型暗色是它自己的皮；真实看板跟随 T3 主题设置，两种主题都必须可读。
- 远程机器项目数暂时为 0（没有远程快照），chips 如实显示，不造假数据。
- 采集器快照每分钟刷新一次，跟随采集器节奏，不额外扫盘。
- 容器写操作接口只监听回环地址，安全边界靠本机 + 前端二次确认；**未对生产 Portainer 实际执行过写操作**（要试先经用户确认）。
- 远程环境展开看项目已实现，但 dev 库没配远程环境，未实测；需在配了 SSH 环境的环境里验收。
